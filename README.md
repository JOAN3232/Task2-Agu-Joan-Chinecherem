# Royal Crest Hotel

A luxury hotel and resort website designed to showcase premium accommodations, world-class amenities, elegant hospitality, and seamless guest experiences.

## Overview

Royal Crest is a modern luxury hotel website built with HTML, CSS, and JavaScript. The project focuses on premium user interface design, responsive layouts, smooth interactions, and an elegant hospitality-inspired aesthetic.

The website features a cinematic hero section, luxury room showcases, hotel amenities, reservation call-to-actions, and a fully responsive design optimized for desktop, tablet, and mobile devices.

## Features

- Responsive luxury hotel website
- Transparent glass-effect navigation bar
- Mobile hamburger menu
- Cinematic hero section
- Luxury room showcase cards
- Hotel amenities and services section
- Reservation and booking call-to-action
- Scroll reveal animations
- Premium typography and color palette
- Mobile-first responsive design
- Elegant hover effects and transitions

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Google Fonts

## How To Run

1. Download the project files.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Launch using Live Server.

Or simply open:

```bash
index.html
```

in your browser.
